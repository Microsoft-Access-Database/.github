## Inside Microsoft Access

Microsoft Access is a local Windows database app with a named access desk, a short table list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a desktop database you already keep and holds only the form that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra forms wait for their own title. Microsoft Access starts with a local profile and does not need a complex account system.
